# v0.2.0 节点验收记录

验收日期：2026-10-24。环境：Windows，Godot 4.7.2，Python 标准库与 SQLite。

## 无界面一天模拟与跨进程恢复

使用独立 SQLite 数据库依次执行，每条命令都启动新的 Python 进程，全程不启动 Godot 或窗口：

1. `simulate-day`：从第 1 天 07:50 推进 24 小时，并创建快照 #1。
2. 再执行 `simulate-day`：推进到下一天，创建另一个快照。
3. `restore --snapshot-id 1`：恢复第一次保存的世界。
4. `state`：再开一个进程确认恢复结果已写入数据库。

结果：全部通过。恢复时钟为 tick **3820**，即**第 2 天 07:50**，与首个快照一致；3 位 NPC 的完整位置、路线、日程及访问记录均一致；再次启动读取的完整世界与恢复结果一致。

- **13 项 Python 集成测试通过**，包括实际 HTTP 请求、一天日程与日志、数据库完整性、恢复后继续运行一致性、跨进程重启、事务回滚、存档版本、并发请求及数据库单写入者锁。
