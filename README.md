# 橡树镇 · Oak & Ember

一个可直接运行的 **Godot 4 像素校园小镇原型**。以暖色砂岩、红瓦建筑和树荫步道表现校园小镇的日常，参考星露谷与 Stanford Smallville 的俯视角社区氛围。地图和人物素材为本项目原创程序绘制，未使用参考游戏的资源。

![小镇实机画面](docs/town-preview.png)

## 启动

需要 **Godot 4.3 或更新的标准版**，本项目在 Windows 上使用 **Godot 4.7.2** 验证，不依赖 .NET、外部插件、网络或 AI 服务。

1. 用 Godot 导入本目录的 `project.godot`。
2. 等待首次资源导入，按 **F6 / F5** 运行主场景。
3. Windows 也可以直接双击 **`launch.bat`**：自动寻找 PATH 或 `D:\Godot` 中的引擎，首次运行会自动导入资源。

自定义引擎路径：

```powershell
.\launch.ps1 -GodotPath 'C:\Tools\Godot.exe'
```

游戏画面为 1440 × 900，可缩放窗口。原始地图为 544 × 368 像素、34 × 23 格，使用最近邻采样放大。中文字体通过操作系统字体回退加载，无须分发商业字体。

## 已完成

- 6 栋剖面建筑：图书馆、咖啡馆、学堂、2 栋住宅与艺术工作室；另有公园、中央广场、湖畔，共 9 处日程地点。
- 玩家四方向逐格移动、人物朝向和步行动画。
- 点击地面后使用 `AStarGrid2D` 四邻域寻路；建筑、树干、长椅、喷泉、湖水及边界会阻挡通行。
- 3 位具有独立资料、角色配色和固定日程的 NPC，自动寻路与每日循环。
- 点击居民或侧边名字，查看简介、活动、目的地和当天日程；寻找按钮前往该居民点击时的位置。
- 附近按 E 打招呼；支持暂停、1× / 4× / 12×、快进一小时、路线显示、重置及简单黄昏变化。

本阶段专注场景、UI 和操作逻辑。建筑内部以剖面美术展示，NPC 的建筑活动地点位于门前；没有室内切换、种田、经济或生成式对话。NPC 可以彼此穿过，避免固定日程中的相互阻塞。

## 操作

| 输入 | 功能 |
| --- | --- |
| WASD / 方向键 | 四方向移动，键盘输入接管点击路线 |
| 左键点击地面 | 自动寻路 |
| 左键点击居民 / 右侧名字 | 查看居民信息 |
| Tab | 切换选中的居民 |
| E | 与距离约两格以内的居民打招呼 |
| Esc | 取消玩家路线 |
| 空格 | 暂停或继续 NPC 与时钟，玩家仍可移动 |
| R | 切换 NPC 路线显示 |
| 底部 1× / 4× / 12× | 调整时钟与 NPC 移动速度 |
| 底部 +1h | 快进一小时，NPC 重新计算目的地并实际走过去 |
| 底部重置 | 回到第 1 天 07:50 |

1× 时现实 1 秒 = 游戏 2 分钟。玩家速度不随 NPC 加速改变。

## 验收 3 位居民

启动时间为 07:50，等待 5 秒后 3 位居民在 08:00 分别出发。选择 **12×** 可快速观察上午活动；使用 **+1h** 可以跳到不同日程节点，观察路线及活动面板更新。为看清抵达过程，每次跳时后留一点行走时间。

| 居民 | 固定日程 |
| --- | --- |
| 米娅 · 图书管理员 | 08:00 图书馆 → 11:00 咖啡馆 → 13:00 图书馆 → 17:00 公园 → 19:00 家 |
| 奥利弗 · 咖啡师 | 08:00 咖啡馆 → 12:00 广场 → 13:00 咖啡馆 → 17:00 湖畔 → 19:00 家 |
| 里奥 · 艺术系学生 | 08:00 学堂 → 11:00 公园 → 13:00 咖啡馆 → 15:00 工作室 → 18:00 湖畔 → 20:00 工作室 |

午夜自动进入下一天并重复日程，NPC 连续行走，不会瞬移。快速连续跳时会直接切换到当前时间对应的任务，不补演被跳过的活动。

## 目录和扩展

```text
project.godot          项目入口
scenes/town.tscn       主场景
scripts/town.gd       场景绘制、UI、操作、时钟、NPC 资料及日程
scripts/world.gd      地图尺寸、建筑碰撞、地点、A* 网格
scripts/resident.gd   NPC 日程选择和实际移动
assets/              原创地图、四方向三帧人物素材及图标
tools/generate_art.py 可复现的美术生成源文件（可选，需要 Pillow）
tests/test_town.gd    Godot 自动验收脚本
```

修改日程：编辑 `town.gd` 的 `DATA`，时间以当天分钟数表示。增加地点：同时修改 `world.gd` 的地点、碰撞数据和美术生成脚本。素材已提交，正常运行无需 Python。
